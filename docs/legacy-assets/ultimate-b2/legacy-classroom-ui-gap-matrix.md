## Boundary conclusion

The original 60×60 and 64×64 controls are already large enough for many classroom contexts; the 40×40, 41×41, 42×42, and 45×45 variants should remain at native pixel size inside a larger semantic `<button>` rather than being resampled. The button container—not the art—should provide the accessible target, focus ring, label, tooltip, disabled semantics, and safe spacing.

Teacher answer/reveal, score, annotation, save/open, and presentation-tool assets must remain in the Teacher entry tree. Hiding them in Student CSS would still ship the bytes and is not an acceptable boundary. This task adds no runtime imports, so current Teacher and Student behavior is unchanged.
