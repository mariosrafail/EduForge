# Unit and group identity

A source number is meaningful only inside its source root and component. It is never a project-global Unit ID.

For example, the following are distinct:

```text
book1 / unit    / 3  → Students Book · Unit 3
book1 / work    / 3  → Workbook · Unit 3
book1 / grammar / 3  → Grammar Book · Unit 3
book1 / test    / 3  → Tests · Group 3
```

The label is a presentation overlay. The stable key is derived from the three raw source identity fields. Parts and pages inherit that parent identity, and hotspots, activities, and reviews resolve through it.

Continuity is diagnostic rather than coercive. Missing numbers, duplicate scoped numbers, principal Unit 11, unknown roles, and menu mismatches produce explicit warnings. They do not cause renumbering, truncation, or a forced ten-Unit result.

Supplementary components can legitimately use numbers. Their grouping kind prevents them from inflating principal Unit selectors or being mislabeled as pedagogical Units.
